# ✅ چک‌لیست ۲۵ موردی ارزیابی نهایی UI/UX

قبل از تحویل هر کامپوننت یا صفحه به کاربر، این چک‌لیست را بررسی کنید:

## ۱. سلسله‌مراتب و زیبایی بصری (Visual Hierarchy)
- [ ] دکمه اصلی (Primary CTA) به وضوح شاخص‌تر از دکمه‌های ثانویه است؟
- [ ] وزن فونت‌ها و رنگ‌ها اهمیت داده‌ها را به درستی تفکیک می‌کنند؟
- [ ] کارت‌ها دارای سایه ملایم مدرن (`shadow-xs` / `shadow-sm`) و حاشیه نازک (`border-slate-200/80`) هستند؟
- [ ] پس‌زمینه‌ها دارای لایه‌بندی عمق (Canvas `bg-slate-50` vs Cards `bg-white`) هستند؟
- [ ] از رنگ‌های جیغ و ناسازگار خودداری شده است؟

## ۲. زبان فارسی، راست‌چین و تایپوگرافی (RTL & Typography)
- [ ] جهت صفحه `dir="rtl"` و تراز متن‌ها درست است؟
- [ ] از فونت استاندارد فارسی (مانند Vazirmatn) با `leading-relaxed` استفاده شده است؟
- [ ] مبالغ با جداکننده سه‌رقمی و ارقام فارسی فرمت شده‌اند؟
- [ ] آیکون‌های ناوبری (فلش‌ها و چورون‌ها) جهت‌گیری صحیح RTL دارند؟
- [ ] عناوین و برچسب‌های فارسی روان، مؤدبانه و حرفه‌ای هستند؟

## ۳. فاصله‌گذاری و واکنش‌گرایی (Spacing & Responsive)
- [ ] فواصل بر مبنای گرید ۸ پیکسلی (`p-2`, `p-4`, `p-6`, `gap-4`) تنظیم شده‌اند؟
- [ ] صفحه در رزولوشن موبایل (`375px` و `414px`) بدون اسکرول افقی ناخواسته نمایش می‌یابد؟
- [ ] جداول طولانی در موبایل قابلیت نمایش کارتی یا اسکرول لمسی تمیز دارند؟
- [ ] اندازه دکمه‌ها برای لمس با انگشت در موبایل حداقل `44x44px` است؟

## ۴. حالت‌های کامپوننت و تعاملات (States & Micro-interactions)
- [ ] حالت هاور (Hover) و فشرده شدن (`active:scale-[0.98]`) دکمه‌ها حس فیزیکی دارد؟
- [ ] حالت بارگذاری (Skeleton یا Spinner) برای داده‌های غیرهمگام پیاده شده است؟
- [ ] حالت خالی (Empty State) همراه با آیکون و دکمه CTA طراحی شده است؟
- [ ] حالت خطا (Error State) با رنگ قرمز/رز و پیام شفاف وجود دارد؟

## ۵. ارگونومی مالی و حسابداری (Financial UX)
- [ ] واریز/درآمد/سود با رنگ سبز (`emerald`) و علامت `+` مشخص شده است؟
- [ ] برداشت/هزینه/بدهی با رنگ قرمز (`rose`) و علامت `-` مشخص شده است؟
- [ ] واحد پولی (تومان / ریال) در کنار اعداد یا سرستون‌ها تصریح شده است؟
- [ ] فیلدهای ورود مبالغ حین تایپ جداکننده هزارگان اعمال می‌کنند؟

## ۶. دسترس‌پذیری و استانداردها (Accessibility)
- [ ] کنتراست رنگ متون با پس‌زمینه حداقل 4.5:1 است؟
- [ ] حلقه فوکوس کیبورد (`focus-visible:ring-2`) فعال است؟
- [ ] دکمه‌های آیکونی دارای `aria-label` هستند؟
