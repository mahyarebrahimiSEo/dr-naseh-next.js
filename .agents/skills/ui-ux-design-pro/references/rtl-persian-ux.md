# 🇮🇷 استانداردهای رابط کاربری فارسی و راست‌چین (Persian & RTL UX Standards)

این سند مرجع تخصصی برای طراحی رابط‌های کاربری فارسی، راست‌چین (RTL) و سامانه‌های مالی و حسابداری است.

---

## ۱. تنظیمات پایه جهت و زبان (Direction & Language Setup)

- تگ والد ریشه همیشه باید شامل `dir="rtl"` و `lang="fa"` باشد:
  ```html
  <html lang="fa" dir="rtl">
  ```
- در Tailwind CSS، از کلاس‌های منطقی (Logical Properties) استفاده کنید:
  - `start-0` / `end-0` به جای `left-0` / `right-0`
  - `ms-3` / `me-3` به جای `ml-3` / `mr-3`
  - `ps-4` / `pe-4` به جای `pl-4` / `pr-4`
  - `text-start` / `text-end` به جای `text-left` / `text-right`

---

## ۲. تایپوگرافی و فونت‌های فارسی (Persian Typography)

- **فونت‌های پیشنهادی با ترتیب اولویت**:
  `fontFamily: { sans: ['Vazirmatn', 'IRANSansX', 'Dana', 'Yekan Bakh', 'system-ui', 'sans-serif'] }`
- **فاصله خطوط (Line-Height)**:
  خطوط متن فارسی نیاز به ارتفاع بیشتری نسبت به انگلیسی دارند. همیشه برای متون چندخطی از `leading-relaxed` (1.625) یا `leading-loose` استفاده کنید.

---

## ۳. فرمت‌بندی اعداد و مبالغ پولی (Number & Currency Formatting)

در نرم‌افزارهای مالی و حسابداری، اعداد و مبالغ باید همیشه خوانا، با جداکننده ۳ رقمی و تبدیل شده به ارقام فارسی نمایش داده شوند:

```javascript
// تابع استاندارد فرمت‌بندی مبالغ به تومان یا ریال با ارقام فارسی
export const formatCurrency = (amount, unit = 'تومان') => {
  if (amount === null || amount === undefined || isNaN(Number(amount))) {
    return '۰ ' + unit;
  }
  const formatted = new Intl.NumberFormat('fa-IR').format(amount);
  return `${formatted} ${unit}`;
};

// تابع فرمت‌بندی درصد
export const formatPercent = (percent) => {
  return new Intl.NumberFormat('fa-IR', { style: 'percent', maximumFractionDigits: 1 }).format(percent / 100);
};
```

### قواعد نمایش داده‌های مالی:
1. **تومان در برابر ریال**: همیشه واحد پول (تومان یا ریال) به طور واضح در کنار عدد یا هدر ستون قید شود تا کاربر دچار خطای محاسبه نشود.
2. **بدهکار / بستانکار و سود / زیان**:
   - **واریز / بستانکار / سود**: رنگ `emerald-600` همراه با علامت مثبت (`+ ۱۲,۵۰۰,۰۰۰ تومان`).
   - **برداشت / بدهکار / هزینه**: رنگ `rose-600` همراه با علامت منفی (`- ۳,۴۰۰,۰۰۰ تومان`).
3. **تراز بودن ارقام (Tabular Numbers)**: در جدول‌ها همیشه از کلاس `tabular-nums` یا فونت‌های با عرض عدد یکسان استفاده کنید تا ارقام زیر هم کاملاً تراز شوند.

## ۴. قوانین معکوس‌سازی آیکون‌ها در RTL (Icon Flipping Rules)

در محیط راست‌چین، همه آیکون‌ها نباید معکوس شوند:

### ✅ آیکون‌هایی که **باید** معکوس (Flip) شوند:
- فلش‌های ناوبری (Next / Previous / Back / Forward)
- آیکون‌های گام‌بندی و مراحل (Breadcrumbs, Steps)
- نمودارهای جهت‌دار خطی و روندها

### ❌ آیکون‌هایی که **نباید** معکوس شوند:
- دکمه‌های کنترل مدیا (Play, Pause, Fast-forward)
- آیکون ساعت، تقویم و زمان
- علامت چک‌مارک (تیک سبز)، ضربدر (بستن)، هشدار و اطلاعات
- نمادهای ریاضی (+, -, ×, ÷)
- لوگوی برندها و کارت‌های اعتباری

---

## ۵. ارگونومی فرم‌ها در زبان فارسی

1. **مکان برچسب (Label)**: برچسب‌ها باید در سمت راست و بالای فیلد ورودی قرار گیرند (`text-right font-medium text-slate-700`).
2. **محل قرارگیری واحد پول**: واحد "تومان" یا "ریال" باید به عنوان پسوند در سمت چپ فیلد (یا بر اساس ساختار RTL در انتهای ورودی) با رنگ ملایم `text-slate-400` نمایش یابد.
3. **جداکننده خودکار هنگام تایپ**: فیلدهای مبالغ مالی باید هنگام تایپ کاربر، عدد را لحظه‌ای ۳ رقم ۳ رقم جدا کنند تا خواندن مبالغ میلیونی/میلیاردی آسان باشد.
