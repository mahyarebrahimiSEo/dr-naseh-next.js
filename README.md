# 🏥 سامانه جامع کلینیک تخصصی دکتر ناصح یوسفی
### Fullstack Healthcare Web Application & Enterprise RESTful API

این پروژه شامل وب‌سایت رسمی و سامانه مدیریت نوبت‌دهی، مقالات و خدمات کلینیک تخصصی طب فیزیکی، توانبخشی و الکترودیاگنوز **دکتر ناصح یوسفی** است که بر مبنای معماری ماژولار و تفکیک کامل فرانت‌اند و بک‌اند بازآرایی و سازمان‌دهی شده است.

---

## ⚡ راه‌اندازی سریع با یک کلیک (Quick Start)

برای اجرای تمامی بخش‌های پروژه (سرور بک‌اند + وب‌سایت فرانت‌اند)، کافیست روی فایل زیر دابل‌کلیک کنید:

👉 **`run website.bat`**

این اسکریپت خودکار:
1. وجود Node.js را بررسی می‌کند.
2. پکیج‌های فرانت‌اند و بک‌اند را در صورت نیاز به طور خودکار نصب می‌کند.
3. دیتابیس را پیکربندی کرده و داده‌های اولیه و حساب کاربری ادمین را بذردهی می‌کند.
4. سرور Express بک‌اند را روی پورت **5000** بالا می‌آورد.
5. وب‌سایت Next.js فرانت‌اند را روی پورت **3000** اجرا می‌کند.
6. مرورگر پیش‌فرض شما را به صورت خودکار با آدرس `http://localhost:3000` باز می‌کند.

## 📁 ساختار منظم و تفکیک‌شده پروژه (Project Structure)

پوشه ریشه پروژه به صورت کاملاً تمیز، ساختارمند و با حداقل فایل‌های اضافه سازمان‌دهی شده است:

```text
dr_naseh_next/
│
├── ⚙️ backend/               # وب‌سرویس و هسته پردازشی (Express.js + TypeScript + Prisma)
│   ├── prisma/             # مدل‌های دیتابیس SQLite و اسکریپت‌های مایگریشن
│   ├── src/                # کدهای سورس بک‌اند (ماژول‌ها، کنترلرها، سرویس‌ها، امنیت)
│   ├── package.json        # وابستگی‌های بک‌اند
│   └── README.md           # مستندات کامل فنی API و کاتالوگ اندپوینت‌ها
│
├── 🌐 frontend/              # وب‌سایت تعاملی مراجعین (Next.js 16 + React 19 + Tailwind CSS)
│   ├── public/             # تصاویر، فونت‌ها و فایل‌های استاتیک
│   ├── src/                # صفحات، کامپوننت‌ها و کلاینت API
│   ├── next.config.ts      # پیکربندی Next.js
│   └── package.json        # وابستگی‌های فرانت‌اند
│
├── 📜 scripts/               # اسکریپت هماهنگ‌ساز و اجراکننده پایدار
│   └── run.js              # فرآیند رانر هم‌زمان بک‌اند و فرانت‌اند
│
├── 🚀 run website.bat        # لانچر اصلی و تک‌کلیک پروژه
├── 📄 README.md              # راهنمای کلی سیستم
└── 🔒 .gitignore             # نادیده‌گیری فایل‌های موقت و build
```
